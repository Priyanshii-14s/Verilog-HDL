# Verilog HDL Practice & Projects

Welcome to my Verilog HDL repository! 

I am an **Electronics and Communication Engineering student** currently learning Digital System Design and Hardware Description Languages (HDL). 

## 📌 About This Repository

This repository serves as a practical log of my learning journey. Here, I write, synthesize, and document custom Verilog implementations ranging from fundamental combinational logic gates to complex sequential circuits.

For each topic, I upload:
* Well-structured Verilog source code (`.v`)
* RTL schematics generated in Xilinx Vivado (`.png`)
* Clean documentation explaining truth tables and underlying hardware logic
